Welcome to the CALM archive!============================This archive represents the final state of the CALM assembler as written by P. Fäh. Thefiles are organised as follows:Directory			Content------------------------------------------------------------------------------------------Binaries\English		English binaries for the CALM assemblerBinaries\French			French binaries for the CALM assemblerBinaries\German			German binaries for the CALM assemblerSource				Source code for the CALM assemblerDoc\English			English documentation for the CALM assemblerDoc\French			French documentation for the CALM assemblerDoc\German			German documentation for the CALM assemblerProcessors\Modules		The subdirectories contain processor modules for the CALM 				assembler and their source, as well as some documentationProcessors\Development kit	Development kit for the CALM assembler modulesUtilities\Binaries		Binaries for CALM assembler utilitiesUtilities\Source		Source for CALM assembler utilitiesWeb pages			Original CALM assembler web pages This archive was created on the 23. September 1998 by Sebastian Gerlach.
